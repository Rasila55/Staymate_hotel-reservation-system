# StayMate – Hotel Reservation System

StayMate is a web-based hotel reservation system developed as a BCA academic project. It allows users to explore hotel and room information and manage hotel reservation-related activities through a web application.

## About the Project

The main purpose of StayMate is to simplify hotel reservation management through a digital platform. The project demonstrates frontend development, backend programming, and database management using PHP and MySQL.

## Technologies Used

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Development:** XAMPP

## Features

- Hotel information management
- Room management
- User management
- Reservation management
- Database connectivity
- Web-based user interface

## Installation and Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Move the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open phpMyAdmin and import the project's database SQL file.
6. Update the database connection settings if required.
7. Open your browser and visit:

```text
http://localhost/StayMate/
```
